# Mohammad Saiduzzaman Sayed — PhD Research Website

A clean, responsive academic personal website for a PhD applicant in Data Science / Computer Science.

## Files
- `index.html` — website content and structure
- `style.css` — visual design and responsive layout
- `script.js` — mobile menu, active navigation, and dynamic year
- `assets/` — place your CV PDF here

## Before publishing
1. Replace `your.email@example.com`.
2. Replace all `href="#"` social/profile links with your real Google Scholar, GitHub, LinkedIn, and ORCID URLs.
3. Put your CV at:
   `assets/Mohammad_Saiduzzaman_Sayed_CV.pdf`
4. Review all research/project wording and update it as your work develops.
5. Update publication metadata as needed.

## GitHub Pages
Create a repository such as `sayed-phd-website`, upload these files, then:
Settings → Pages → Deploy from a branch → `main` → `/root`.

Your site will be available at:
`https://YOUR-USERNAME.github.io/sayed-phd-website/`
